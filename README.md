# 🐼 The Pandas Pact

Welcome to the official repository of **The Pandas Pact** – a cross-cultural, collaborative team committed to learning, growing, and delivering impactful work together. This repository houses our comprehensive phishing email detection project, including all data analysis, visualizations, and research findings.

---

## 🎯 Project Overview

This project focuses on **phishing email detection and analysis** using machine learning and statistical methods. We analyze email patterns, linguistic features, and psychological manipulation tactics to identify characteristics that distinguish phishing emails from legitimate ones.

### 📊 Key Findings

- Achieved **82% accuracy** in phishing detection using Random Forest classification
- Identified distinct psychological manipulation patterns in phishing emails
- Generated comprehensive statistical analysis with confidence intervals
- Created 10 detailed visualizations for presentation and analysis
